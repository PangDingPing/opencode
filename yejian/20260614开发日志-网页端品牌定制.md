# 2026.06.14网页端品牌定制 - 修改说明

本次修改将 opencode 网页端的浏览器标签标题、网页图标（Favicon）、"新建会话"页面顶部的品牌标识替换为广东冶建图审 AI 工作台的定制内容。

## 一、前置操作

1. 拉取远程 dev 分支最新更新
2. 基于 dev 创建并切换到新分支 `branding-update`

```
git pull origin dev
git checkout -b branding-update
```

## 二、修改文件清单

### 1. 浏览器标签标题与 Favicon

**文件**：`packages/app/index.html`

**修改内容**：

- `<title>` 从 `OpenCode` 改为 `广东冶建图审AI工作台`
- 三个 favicon 引用统一指向 `/LOGO1.ico`（不再使用 opencode 默认的 favicon 系列）

修改后 head 段相关代码如下：

```html
<title>广东冶建图审AI工作台</title>
<link rel="icon" type="image/x-icon" href="/LOGO1.ico" sizes="any" />
<link rel="shortcut icon" href="/LOGO1.ico" />
<link rel="apple-touch-icon" sizes="180x180" href="/LOGO1.ico" />
```

### 2. "新建会话"页面顶部品牌标识

**文件**：`packages/ui/src/v2/components/wordmark-v2.tsx`

**修改内容**：

- 删除原组件内的整个 `<svg>` 块（opencode 字标 SVG，原 viewBox 为 720.002 129.001）
- 组件返回改为 `<img>` 标签，引用 `/ai-workbench.png`，保留原 `class` 透传
- 同步把 props 类型从 `Pick<ComponentProps<"svg">, "class">` 改为 `Pick<ComponentProps<"img">, "class">`
- 移除不再使用的 `createUniqueId` 导入

修改后完整文件内容如下：

```tsx
import type { ComponentProps } from "solid-js"

export function WordmarkV2(props: Pick<ComponentProps<"img">, "class">) {
  return <img src="/ai-workbench.png" alt="wordmark" class={props.class ?? ""} />
}
```

**调用方**：仅在 `packages/app/src/components/session/session-new-design-view.tsx` 一处使用，调用代码无需调整（class 透传仍兼容）。

## 五、启动验证

修改完成后分别启动前后端进行验证：

- **后端**（在 `packages/opencode` 目录下）：
  ```
  bun run --conditions=browser ./src/index.ts serve --port 4096
  ```
- **前端**（在 `packages/app` 目录下）：
  ```
  bun dev -- --port 4444
  ```

浏览器访问 `http://localhost:4444` 即可看到以下效果：

1. 浏览器标签显示"广东冶建图审AI工作台"
2. 标签左侧、收藏夹图标为广东冶建 LOGO
3. "新建会话"页面顶部显示 AI 工作台 图片（替换原 opencode 字标）
