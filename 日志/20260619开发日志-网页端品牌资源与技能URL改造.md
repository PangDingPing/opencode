### 2. 现行规范 / 现行图集 url 改造（关键路径）

**文件**：`packages/app/public/yejian/skills.json`

**问题溯源**：6-16 日志中"审查相关"分组下两项 url 模式技能写的是 `/YEJIAN/现行规范数据2026-02-04.html` / `/YEJIAN/最新图集数据20260206.html`（**大写**前缀）。opencode 后端 catch-all 路由（`packages/opencode/src/server/shared/ui.ts:78-107`）只查 `embeddedWebUI` 字典 + 代理到 `app.opencode.ai`，**不识别任意挂载目录**。点击后只能回退到 SPA 的 `index.html`，显示空壳页面。

**第一次尝试**（失败）：把 url 改为 `file:///E:/AI/YEJIAN/...` 直接走系统协议。

- 现象：DevTools Console 抛出 `Not allowed to load local resource: file:///E:/AI/YEJIAN/...`
- 原因：浏览器（Chrome/Edge）禁止从 **HTTPS 页面** 加载 `file://` 协议资源（安全策略，不可绕过）
- 结论：file:// 协议不可行

**第二次尝试**（失败）：推断是不是 `/YEJIAN/`（大写）与前端 public 目录 `/yejian/`（小写）混淆。

- 排查：实际两者在 Linux 文件系统里是不同目录（大小写敏感），opencode 后端字典 key 是 `yejian/skills.json`，与 `/YEJIAN` 没有半毛钱关系
- 结论：不是大小写问题

**最终方案**（成功）：把 HTML 复制到前端 public 目录，url 改回 `/yejian/...`（**小写**），走 Vite dev server / opencode 构建字典的 static path。

**修改后的 url 字段**：

```json
"url": "/yejian/%E7%8E%B0%E8%A1%8C%E8%A7%84%E8%8C%83%E6%95%B0%E6%8D%AE2026-02-04.html"
"url": "/yejian/%E6%9C%80%E6%96%B0%E5%9B%BE%E9%9B%86%E6%95%B0%E6%8D%AE20260206.html"
```

中文文件名做了 UTF-8 URL 编码，避免不同浏览器对未编码中文路径的解析差异。

**顺手把 `keyword` 字段从原来的 url 改回中文词**：

```json
"keyword": "现行规范数据"
"keyword": "现行图集数据"
```

这样输入中文关键词能正确匹配到这个技能。

## 六、附注

### 6.1 浏览器安全策略的"硬墙"

本次会话证明：**opencode web 部署在 HTTPS 下时，`file://` 协议在 web 内不可用**——这不是配置问题，是 Chrome/Edge 浏览器层面的安全策略。

| 协议组合 | 结果 |
|---|---|
| HTTPS 页面 + `file://` url | ❌ `Not allowed to load local resource` |
| HTTP 页面 + `file://` url | ✅ 可用（但要求 opencode 走 HTTP 不能走 HTTPS） |
| 任意协议 + `http(s)://...` url | ✅ 走 web 协议，最稳 |

**对冶建的实际意义**：Docker 模式（HTTPS）下任何想引用"本地资源"的需求，都必须把文件**搬进 opencode 的 public 目录**（dev 模式 / Docker 模式通用），或者走单独的 HTTP 静态服务容器（详见 6.2）。

### 6.2 几种"挂载目录资源"方案的对比

| 方案 | 工作量 | 适用场景 | 局限 |
|---|---|---|---|
| **复制到 public/yejian/**（本次采用） | 1 次复制 | dev + Docker 都行 | 文件更新需要重新复制 |
| **改 [ui.ts](file:///d:/AI/opencode/packages/opencode/src/server/shared/ui.ts) 让后端读 /YEJIAN 挂载点** | 改 1 个文件 + ForceRebuild | 长期方案，但需要 dev 模式 + HTTP | Docker HTTPS 模式下还是会被浏览器拦 |
| **另起一个 nginx 静态容器** | 写个 docker-compose | 资源更新频繁 | 多一个端口要记 |
| **mklink 软链接** | 1 行命令 | 仅 dev 模式 | Docker 镜像不识别 Windows junction |
