# 2026.06.19 文件树默认隐藏 dotfiles - 修改说明

本次修改让 opencode 网页端 session 页面右侧的文件树，在"所有文件"标签页下默认隐藏以 `.` 开头的文件夹和文件（如 `.git`、`.vscode`、`.env`、`.DS_Store` 等），让日常审查场景的文件浏览更干净。"变更"标签页保持原样不变，避免误伤修改过的隐藏配置文件。

## 一、需求背景

- 文件树在"所有文件"模式下会列出项目根目录下的所有目录项
- 默认会显示 `.git`、`.vscode`、`node_modules` 等 dotfiles，干扰审查视线
- 用户希望默认隐藏 dotfiles，但不强制——保留"变更"标签页完整显示

## 二、方案选择

提了 3 个方案，最终选 1+3 组合：

1. **方案 1**：直接硬过滤掉 dotfiles（简单但无开关）
2. **方案 2**：做成 settings 里的可配置开关（改动大）
3. **方案 3**：只过滤"所有文件"标签，不过滤"变更"标签（体验最好）

**最终方案**：方案 1 + 方案 3 组合
- "所有文件"模式：`name.startsWith(".")` 一律不显示
- "变更"模式：保持原样，dotfiles 该看还是能看到

## 三、代码定位

关键调用链：

1. `packages/app/src/context/file.tsx` 第 81 行：`sdk.client.file.list({ path: dir })` 拉取后端文件列表
2. `packages/app/src/context/file/tree-store.ts` 第 148 行 `children()`：返回目录下的所有子节点
3. `packages/app/src/components/file-tree.tsx` 第 327 行 `nodes` 计算：决定显示哪些节点（核心过滤点）

改动点定在第 3 步，不动后端、不动 store。

## 四、修改文件清单

### `packages/app/src/components/file-tree.tsx`（1 个文件）

#### 改动 1：`nodes` 计算函数（核心过滤）

**位置**：第 327-333 行

**改动前**：

```ts
const nodes = createMemo(() => {
  const nodes = file.tree.children(props.path)
  const current = filter()
  if (!current) return nodes
  ...
```

**改动后**：

```ts
const nodes = createMemo(() => {
  const raw = file.tree.children(props.path)
  const current = filter()
  // "所有文件"模式：默认隐藏以 "." 开头的文件/文件夹（如 .git、.vscode、.env 等）
  if (!current) return raw.filter((node) => !node.name.startsWith("."))
  const nodes = raw
  ...
```

**关键判断条件**：`!current`（即 `filter()` 返回 `undefined`）

- 没有 filter 时 = "所有文件"模式 → 多过一道 dotfile 过滤
- 有 filter 时（"变更"模式，从父节点传下来）→ 走原逻辑

**注意点**：把内部 `const nodes` 改成 `const raw`，避免和前面 `return raw.filter(...)` 出现 shadow 冲突；下面用 `const nodes = raw` 接住原引用，函数体其余部分零改动。

## 五、影响范围

- ✅ **不影响的**：
  - 后端 API（`sdk.client.file.list`）未动
  - 文件树 store（`tree-store.ts`）未动
  - 文件打开、搜索（`Ctrl+P`）、`@` 引用文件、命令面板仍可访问 dotfiles
  - `.gitignore` 标记的"已忽略"文件逻辑（`node.ignored`）未动
- ⚠️ **行为变化**：
  - "所有文件"标签下：dotfiles 不再显示
  - "变更"标签下：dotfiles 该显示还显示
