# 2026-06-20 Skill 四角互补重构（feat）

## 一、需求背景

按《Skill 体系"四角互补"重构计划 v3》，将 4 个思考类 skill（头脑风暴 / 梳理头绪 / 决策顾问 / 智囊评审）整合为"发散 → 澄清 → 决断 → 把关"四角互补工作流，在悬浮技能框中以"决策系统（军师）★★"分组集中展示，并删除其它分组下的旧/重复条目。

## 二、备选方案

### case 格式
| 方案 | 描述 | 结论 |

## 五、踩坑记录

1. **JSON 中 ASCII 直引号导致解析失败**：新增 4 个 skill 的 tooltip 字段里，用了 ASCII 直引号 `"`（0x22）包裹触发词（如 `用户说"头脑风暴一下"`），导致 `SyntaxError: Expected ',' or '}' after property value in JSON at position 262 (line 12 column 43)`。修复方案：用 Python 脚本把 3 个 tooltip 行（line 12/27/56）value 中的 ASCII `"` 成对替换为中文引号 `"`/`"`（U+201C / U+201D）。教训：JSON 字符串内必须用中文引号或转义 `\"`，不能用裸 ASCII 引号。临时脚本 `fix_json.py` 已删除，**注意：编辑 JSON 时建议直接用中文引号，避免此类问题**。

2. **第一次 Edit 替换 Word 技能 case 时字符串未匹配**：`isSkill` 验证原本只接受 `typeof v.case === "string"`，如果直接改 JSON 不动前端，整个技能面板会加载失败（"技能 JSON 结构校验失败"）。必须前端 + JSON 同步改。

3. **SolidJS `<For>` 已存在于顶部 import**：不需要新增 import，直接用即可。

4. **`.opencode/skills/` 路径不在 opencode 项目里**：4 个 skill 的 SKILL.md 在 `E:\AI\YEJIAN\.opencode\skills\`（用户家目录下的 YEJIAN 项目），与本项目（opencode 主项目）分离。本次只改悬浮技能框的"快捷入口"，SKILL.md 本身不在本项目。

### 9.1 新增踩坑：8088 端口 bind 失败（WinError 10013）

**现象**：`docker run -p 8088:8088` 报 `ports are not available: exposing port TCP 0.0.0.0:8088 -> 127.0.0.1:0: bind: An attempt was made to access a socket in a way forbidden by its access permissions.`

**根因诊断**：
- 不是 docker daemon 问题（`-P` 自动分配端口能成功，如 `0.0.0.0:32768->8088`）
- 不是单个端口被占用（`netstat` / `Get-NetTCPConnection` 都看不到 8088）
- 不是端口排除范围（`netsh interface ipv4 show excludedportrange` 排除段是 3336/4113-4212/4411-4510/4511-4610/7681-7780/8044-8143/9340-9439/50000-50059/50248，**不包含 8088**）
- **是系统层面禁止 bind 8088/8089**——Python `socket.bind(('0.0.0.0', 8088))` 也失败，错误 `WinError 10013 (WSAEACCES)`；但 bind 9000/12345 正常

**解决**：**重启电脑**即可恢复 8088 端口的 bind 能力（用户已验证）。临时绕过：`docker run -p 9090:8088 ...`（主机端口改 9090）。

**根本原因推测**（未完全验证）：可能是 Trae IDE 沙箱或某个后台服务（如 Windows 防火墙、Defender 实时保护）持续占用/锁定 8088 socket，重启 OS 后释放。
