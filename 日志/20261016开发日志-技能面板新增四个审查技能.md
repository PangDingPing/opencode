# 技能面板新增四个审查技能

## 需求背景

`E:\AI\YEJIAN\.opencode\skills`（审查工作区）下新增了四个面向施工图审查工作流的 skill：

| skillId | 面板名称 | 用途 |
|---|---|---|
| drawing-preprocess | 图纸预处理 | 扫描施工图 PDF/图片是否超出 GLM 视觉输入限制（A0/A1 图幅及复杂矢量直传报 Invalid request parameters / 10013），批量转换并生成审查用图纸清单 |
| standard-downloader | 规范下载 | 按标准号（含/不含年份）或名称关键字查本地规范库，默认把 PDF 下载到用户「标准下载/」目录，优先带条文说明版本；支持联网兜底、学兔兔 QQ 登录下载 |
| extract-review-comments | 提取审查意见 | 从 .doc/.docx 表格式审查意见单提取三个分项的意见概述/回复/落实情况，转标准三行式文本，只输出不存文件 |
| technical-review-report | 技术审查报告 | 基于设计说明 + 上阶段评审意见 + 各专业意见单，按参考文档格式合成技术方案审查报告 docx，内容全溯源 |

需在技能面板（skills.json）的「审查相关」分组、「规范图集自更新」条目下挂载入口。

## 备选方案

- 条目字段（tooltip/keyword/case/prompt）来源：逐个阅读四份 SKILL.md 的 frontmatter description 与正文工作流提炼，不臆造功能描述；格式与 skills.json 现有条目保持一致
- 新增顺序按用户指定：drawing-preprocess → standard-downloader → extract-review-comments → technical-review-report
- 技术审查报告的 prompt：SKILL.md 定义了三类输入资料（资料一设计说明 / 资料二上阶段评审意见 / 资料三各专业意见单），用户要求在 prompt 末尾补充三段【资料N】占位模板，点击后只需替换「（此处填写路径）」
- skill 实现本体留在审查工作区 `E:\AI\YEJIAN\.opencode\skills\`，本仓库只改面板数据，不搬运实现
