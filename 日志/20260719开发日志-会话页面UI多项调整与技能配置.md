## 五、踩坑记录

1. **Ctrl+\ 命令注册位置**：一开始想直接复用 `useSessionCommands`，Grep 后发现该 hook 注册了大量 session 专属命令（消息发送、模式切换等），不适合新建会话页面。改为只注册 `fileTree.toggle` 一个命令，最小侵入
2. **HTML 文件重命名必须先于 skills.json**：先重命名 HTML 让新文件名存在，再改 skills.json 引用，否则 git 会把 skills.json 的 URL 改动识别为引用不存在的文件（虽然不影响提交，但依赖顺序更清晰）
3. **`bun typecheck` 报错 `message-timeline.tsx:585`**：是上游已存在的类型错误，与本次改动无关。本次改动未引入新错误
4. **prompt-input.tsx 新建会话页面按钮删除后外层 div 多余**：第一版只删了 `<TooltipKeybind>` 块，外层 `<div class="pointer-events-none absolute bottom-2 left-2">` 包装层只剩注释，又补了一次 Edit 把整个包装 div 删掉
5. **`file.attach` 快捷键记忆错误**：写 manifest 时一开始写成 `mod+o`，Read 代码 L498-506 确认是 `mod+u`，更正
