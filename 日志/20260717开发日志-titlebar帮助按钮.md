# titlebar 增加帮助按钮：点击打开 yejian_help.pdf

## 需求背景

新建会话页面顶栏需要在用户设置图标（UserMenu，人形头像）旁增加一个帮助问号小图标，点击后在新窗口打开 `D:\AI\opencode\packages\app\public\yejian\yejian_help.pdf` 帮助文件。

## 备选方案

### 帮助文件访问方式

PDF 文件位于 `packages/app/public/yejian/yejian_help.pdf`。前端 `public/` 目录的文件会被 Vite 在开发时直接服务、构建时复制到产物，经 `/yejian/yejian_help.pdf` 路径访问。

- **方案 A（✅ 采用）**：用 `window.open("/yejian/yejian_help.pdf", "_blank", "noopener,noreferrer")` 在新标签页打开，浏览器内置 PDF 阅读器直接展示
- 方案 B：用 `<a href="/yejian/yejian_help.pdf" target="_blank">` 包裹按钮——SolidJS 下不如 `window.open` 简洁
- 方案 C：前端 fetch PDF blob 再展示——过度设计，浏览器原生支持 PDF 渲染

### 图标选择

项目图标库 `packages/ui/src/components/icon.tsx` 已有现成图标：

- **`help` 图标（✅ 采用，L91）**：圆圈内一个问号，符合"帮助"语义
- `info` 图标：信息图标，语义偏向"提示"而非"帮助"
- `settings-gear`（L92）：齿轮，语义是设置

`help` 图标是首选。

### 组件放置位置

titlebar 有两处引用 `<UserMenu />`：
- L711（旧版布局）：`<div id="opencode-titlebar-right" />` 后
- L744（V2 新版布局）：`<div id="opencode-titlebar-right" />` 后

按视觉习惯，帮助问号通常放在用户设置图标**左侧**。

- **方案 A（✅ 采用）**：两处都在 `<UserMenu />` 前加 `<HelpButton />`
- 方案 B：只加在新版布局——会导致旧版布局用户看不到帮助入口

### 代码组织

按项目"模块化改动原则"（自定义改动.md 4.x 节）：

- **方案 A（✅ 采用）**：新建独立组件文件 `help-button.tsx`，titlebar.tsx 只加 import + 两行 JSX
- 方案 B：直接在 titlebar.tsx 内联写按钮——散弹枪修改，且 titlebar.tsx 已 750+ 行，再塞代码不健康

## 文件改动

### 1. 新建 `packages/app/src/components/help-button.tsx`

完整代码（22 行）：

```tsx
import { type Component } from "solid-js"
import { IconButton } from "@opencode-ai/ui/icon-button"

// 顶栏帮助按钮：点击在新窗口打开 yejian_help.pdf 帮助文件
export const HelpButton: Component = () => {
  // 帮助文件路径（构建时由后端从 public/yejian/ 目录提供静态服务）
  const HELP_PDF_URL = "/yejian/yejian_help.pdf"

  const openHelp = () => {
    window.open(HELP_PDF_URL, "_blank", "noopener,noreferrer")
  }

  return (
    <IconButton
      icon="help"
      variant="ghost"
      class="titlebar-icon rounded-md"
      aria-label="帮助"
      onClick={openHelp}
    />
  )
}
```

**设计要点**：
- `icon="help"`：复用图标库现成 help 图标（圆圈问号）
- `variant="ghost"` + `class="titlebar-icon rounded-md"`：与 `UserMenu` 触发按钮样式完全一致，视觉协调
- `onClick={openHelp}`：`IconButton` 透传 `ComponentProps<"button">`，`onClick` 原生支持
- `window.open(url, "_blank", "noopener,noreferrer")`：新标签页打开，`noopener` 防止新页面通过 `window.opener` 操作原页面（安全），`noreferrer` 不泄露 Referer

## 踩坑记录

### 坑 1：以为需要新建图标

一开始担心图标库没有"问号"图标，准备在 `icon.tsx` 加新 SVG。Grep 搜索后发现 `icon.tsx` L91 已有 `help` 图标（圆圈问号），直接复用，避免改上游 `icon.tsx`。

### 坑 2：以为只有一处需要改

最初只注意到 V2 布局（L744）的 `<UserMenu />`，差点漏掉旧版布局（L711）。Grep 确认 titlebar.tsx 内有两处 `<UserMenu />` 引用，两处都加了 `<HelpButton />`，保证新旧布局都有帮助入口。

### 坑 3：virtua 包告警

前端 `bun dev` 启动时 Vite 报告 `virtua/lib/solid/index.jsx` 的 JSX import source 告警。这是上游依赖 virtua 包的问题（它的 .jsx 文件顶部写了 `@jsxImportSource solid-js` 注释，但 Vite esbuild 插件没启用 React automatic JSX transform），不影响运行时行为，SolidJS 的 JSX 由 `vite-plugin-solid` 处理。忽略即可。
