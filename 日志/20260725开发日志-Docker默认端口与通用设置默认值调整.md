# 20260725 开发日志 - Docker 默认端口与通用设置默认值调整

## 需求背景

用户在同一会话中提出两点配置类调整：

1. Docker 部署脚本当前默认端口映射为 `80:8088`，要求统一改为 `8088:8088`，并同步更新 `docker` 目录下相关说明文档。
2. 设置中“通用”菜单页面需要固定为指定开关状态：
   - **关闭**：自动接受权限、显示推理摘要、展开 shell 工具部分、展开编辑工具部分、Command palette、Server status
   - **打开**：显示会话进度条、New layout and designs、系统通知（智能体、权限、错误）、File tree、Custom agents

## 备选方案

1. **Docker 端口**
   - 方案 A：不改脚本默认值，每次调用时手动传 `-HostPort 8088`。
   - 方案 B：修改 `build.ps1` 默认值为 `8088`，并同步修正 `readme.md` 中所有示例与验证地址。
   - 选择方案 B，避免用户每次手动传参，也避免文档与代码默认值不一致。

2. **通用设置默认值**
   - 方案 A：直接修改前端 Settings Context 的 `defaultSettings`，让新用户/新部署首次打开即符合要求。
   - 方案 B：写脚本批量初始化或覆盖用户本地 `settings.v3` 存储。
   - 选择方案 A，因为需求面向“默认状态”，且已有 `withFallback` 持久化回退逻辑，不会破坏已有用户的个人设置。
