## 踩坑记录

### 1. pre-push hook 拦截：stats-app typecheck 失败

**问题**：`@opencode-ai/stats-app#typecheck` 报告 3 个 `RequestEvent` 上 `response` 属性不存在的错误（`src/routes/[lab]/[model].tsx:103`、`src/routes/[lab]/index.tsx:54`、`src/routes/index.tsx:116`），`bun typecheck` 失败导致 push 被拦截。

**根因**：这 3 个错误来自 `d420252`（`.git` 目录恢复 commit），与多用户改造无关。是上游 `solid-start` 类型变化导致的 `RequestEvent.response` 属性已被移除，stats-app 代码未跟进。

**处理**：用户选择跳过 typecheck 推送，用 `git push --no-verify` 绕过 hook。

**后续**：stats-app typecheck 错误需要在另一个 commit 中修复（属于技术债，不影响多用户改造）。

### 2. PowerShell 限制

- `&&` 不是合法语句分隔符（需用 `;` 或分行）
- `head` 命令不可用（需用 PowerShell 原生命令或 `Select-Object`）
- `curl` 是 `Invoke-WebRequest` 别名（需用 `curl.exe`）
