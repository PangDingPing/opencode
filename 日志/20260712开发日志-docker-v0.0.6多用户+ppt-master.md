## 一、需求背景

用户要求制作 Docker 镜像 v0.0.6，6 项要求：

1. 版本号 v0.0.6
2. 特定 docker run 命令（端口 80:8088，挂载 E:\AI\YEJIAN:/YEJIAN，env-file 注入）
3. **api-keys.env 中无 OPENCODE_SERVER_USERNAME、OPENCODE_SERVER_PASSWORD**——用户不希望输入两次密码，只输入用户名及密码
4. 按 ppt-master 精简打包方案安装依赖
5. 启动时默认打开 "/YEJIAN" 项目
6. 参考 docker/readme.md

**核心冲突**：要求 3 与 `bootstrapAdmin()` 的 fail-fast 逻辑冲突——无 `OPENCODE_SERVER_PASSWORD` 时 `process.exit(1)`。

## 二、备选方案

### 方案 A：api-keys.env 放 OPENCODE_SERVER_USERNAME/PASSWORD（否决）
- 优点：bootstrapAdmin 直接用
- 缺点：与 seed-users.json 重复输入密码（用户明确否决）

### 方案 B：seed-users.json 挂载进容器（否决）
- 优点：密码只输一次
- 缺点：用户 docker run 命令未挂载 seed-users.json，需改启动命令

### 方案 C：seed-users.json 烤入镜像（采纳）
- 优点：用户 docker run 命令无需改动；密码只输一次（构建镜像时写入）
- 缺点：改密码要重新构建镜像（但首次登录强制改密，初始密码只是引导用）

## 五、踩坑记录

### 坑 15：迁移脚本也用 @node-rs/argon2

**问题**：`packages/core/src/database/migration/20260625120001_seed_initial_users.ts` L1 `import { hash } from "@node-rs/argon2"`，跟 `user/index.ts` 是同一个跨平台崩溃问题。如果只改 `user/index.ts` 不改迁移脚本，迁移运行时仍会崩。

**发现方式**：`grep -r "@node-rs/argon2" packages/` 发现 3 个文件引用（user/index.ts 注释、package.json 依赖、migration 脚本 import）。

**解决**：从 `user/index.ts` `export hashPassword`，迁移脚本 `import { hashPassword } from "../../user"` 替换 argon2 hash。这样密码 hash 格式统一（scryptSync 的 `salt:hash` 格式），`verifyPasswordHash` 能正确验证。

**教训**：改密码哈希算法时，必须检查所有 hash 调用点（`grep -r "@node-rs/argon2" packages/`），不能只改主文件。

### 坑 16：seed-users.json 挂载方式

**问题**：用户 docker run 命令未挂载 seed-users.json，bootstrapUsers 找不到种子文件。

**解决**：seed-users.json 烤入镜像（/etc/opencode/seed-users.json），Dockerfile 设置 `ENV OPENCODE_SEED_USERS_FILE=/etc/opencode/seed-users.json`。用户启动命令无需改动。
