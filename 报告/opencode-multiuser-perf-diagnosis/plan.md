## 结论先行

多用户加载缓慢的卡点不在网络层，而在服务端事件广播架构：
1. SSE 事件全量广播（无用户过滤，N² 放大）
2. 每个持久化事件一个 SQLite 事务 + DB 位于 Windows bind mount（fsync 慢）
3. event 表无限增长
4. MaxListenersExceededWarning = 11 个并发 SSE 连接（GlobalBus 监听器），是负载指示器而非纯泄漏
